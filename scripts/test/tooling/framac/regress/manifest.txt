# scripts/test/tooling/framac/regress/manifest.txt
# M2 regression wall. One row per historic OOB bug:
#   <kernel.c> | <eva-slevel> | <fix-commit> | <note>
# run-framac-regress.sh compiles each kernel TWICE: default (pre-fix logic) must
# raise >=1 Eva alarm (the detector fires - negative control), and -DFIXED must
# raise 0 (the guard closes it). A kernel where the buggy mode stops firing, or
# the fixed mode alarms, FAILS the gate. Each kernel reproduces the cited access
# verbatim with buffers sized to the real allocation.
# The fix-commit column names the upstream commit that shipped the guard, or
# `unfixed` where the defect is still on upstream master and -DFIXED models a
# proposed guard: that row gates the detector, not a merged fix.
# Audit basis: upstream master ccafdfe51 for the first four rows, 5e628d1e0 for
# glyphrank.c, 3c84890a1 for the two backup rows. Frama-C 32.1, machdep
# gcc_x86_64.
